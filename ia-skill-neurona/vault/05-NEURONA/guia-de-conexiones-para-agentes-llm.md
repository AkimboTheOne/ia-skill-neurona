# Guía de conexiones para agentes LLM

## Propósito

Esta neurona cubre sólo el tramo de conexión: cuándo una captura debe convertirse en conexión entre neuronas y cómo reconocer una conexión útil.

## Regla

Una conexión debe:

- revelar el mismo principio subyacente en notas distintas;
- exponer una contradicción o tensión;
- agrupar tres o más capturas en un patrón;
- o responder una pregunta con evidencia de otra nota.

## Criterio

No confundir coincidencia de palabras con conexión real. La conexión debe aportar secuencia, tensión o insight reutilizable; si no lo hace, vuelve a captura.
