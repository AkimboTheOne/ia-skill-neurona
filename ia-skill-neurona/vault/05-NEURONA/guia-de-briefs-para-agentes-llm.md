# Guía de briefs para agentes LLM

## Propósito

Esta neurona cubre sólo el tramo de brief: cuándo una red de capturas y conexiones ya tiene forma de brief útil.

## Regla

Un brief debe salir sólo cuando hay:

- una tesis central clara;
- prueba concreta;
- transformación del lector;
- y ganchos/cierres que sirvan a comunicación o pensamiento.

## Criterio

Si la evidencia es débil, el brief debe decirlo. No debe compensar falta de prueba con adornos retóricos; en ese caso vuelve a conexión.
