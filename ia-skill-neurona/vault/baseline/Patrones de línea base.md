# Patrones de línea base

## Curaduría

Índice histórico del corpus baseline. La superficie operativa curada está en la [Fuente consolidada de `docs/baseline`](20260513-172100-baseline-source-consolidated.md).

## Síntesis

Este índice agrupa la doctrina base para sistemas de IA orientados a agentes y señala la referencia madre en `agentic-patterns.com` junto con la procedencia primaria de cada archivo.

## Referencia Madre

El catálogo madre para estos patrones es [Awesome Agentic Patterns](https://www.agentic-patterns.com/). Cada archivo conserva además su referencia primaria específica en el frontmatter.

El agente de codificación debe respetar estos patrones cuando opera en este repositorio para la creación, actualización y mejora de skills, plugins y herramientas de IA de primer nivel.
