# Capture: docs/ es la bóveda concreta de la instancia actual del skill

## Interpretación

`docs/` no es el skill. Es la bóveda concreta del proyecto actual desde la cual se instancia `$mem`.

## Consecuencia

El contrato estructural se comparte, pero la semántica depende del proyecto. La forma es reusable; el significado se resuelve por instancia.

## Raw Capture

Idea: el repositorio docs/ de este proyecto es una instanciación concreta de , no el skill en sí. El skill es el contrato reutilizable; la bóveda del proyecto toma forma según su propio contexto, materia prima y necesidades semánticas. La forma se comparte, pero el significado no.
