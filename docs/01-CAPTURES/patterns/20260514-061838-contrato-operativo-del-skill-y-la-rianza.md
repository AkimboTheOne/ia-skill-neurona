# Contrato operativo del skill y la rienda

## Definición

Mientras `$mem` esté activo en la lista de skills, se puede usar para capturar ideas, procesar el inbox, encontrar conexiones, generar briefs y enlazar notas.

## Límite

La habilidad da riendas y herramientas. El LLM conserva la decisión semántica, el contexto y la síntesis.

## Implicación

Esta definición debe madurar como contrato operativo del proyecto, no como una frase aislada. Su valor está en sostener el uso correcto del skill sin confundir estructura con autoría.
