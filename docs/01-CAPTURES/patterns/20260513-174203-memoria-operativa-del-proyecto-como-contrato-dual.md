# Memoria operativa del proyecto como contrato dual

## Decisión

`$mem` debe operar como una memoria curada del proyecto con contrato dual:

- una capa estructural, fija y verificable;
- una capa editorial, flexible y decidida por el LLM.

La estructura fija carpeta, propiedades, formato, referencias y trazabilidad. La capa editorial decide contenido, contexto, vínculos, traducción funcional y calidad final.

## Lecciones Incorporadas

- El skill son riendas, no el jinete.
- La traducción útil es operativa, no literal.
- La fuente original debe seguir siendo evidencia.
- La superficie activa debe simplificar la operación diaria.
- El histórico de conversación debe convertirse en histórico de decisiones.

## Decisiones Adoptadas

- `$mem` usa español como idioma operativo.
- La frontera de responsabilidad queda explícita.
- Las notas nuevas usan YAML frontmatter.
- `docs/baseline` conserva su valor como fuente original curada.
- La capa consolidada en español es la superficie operativa.

## Riedras Implementadas

- `created`, `type`, `status`, `source`, `tags`
- `aliases`, `source_file`, `reviewed`, `confidence` cuando aportan valor
- carpetas estables y utilitarias
- salida de CLI legible por máquinas
- JSON por stdout, errores por stderr
