# El conjunto de patrones de baseline define una doctrina operativa para agentes

## Resumen Afinado

El corpus de `docs/baseline` converge en una doctrina para construir herramientas de IA donde el descubrimiento, la invocación, el registro, las APIs, los manifiestos y la memoria se diseñan para agentes como usuarios primarios.

## Cobertura de Fuente

La fuente completa quedó absorbida en [Fuente consolidada de `docs/baseline`](20260513-172100-baseline-source-consolidated.md).

## Expansión de Agente

Este índice importa porque deja de tratar los documentos base como referencias sueltas. Los presenta como una guía de arquitectura para `$mem`: CLI primero, salida estructurada, manifiestos estáticos, memoria local y referencias legibles por agentes.

## Implicaciones Operativas

- Usa el conjunto baseline como lista de verificación antes de añadir nuevas capacidades.
- Prefiere patrones que reduzcan desperdicio de contexto y ambigüedad.
- Mantén los documentos futuros conectados con estos principios canónicos.
- Convierte patrones externos nuevos en notas procesadas antes de usarlos como guía de diseño.

## Tensiones

El conjunto baseline todavía está madurando. Debe guiar decisiones de diseño, pero cada patrón necesita validación local contra los flujos reales del repositorio y las necesidades del usuario.
