# Brief: skills nativos para agentes

## ONE THING

Los mejores skills se comportan como pequeñas pilas locales para agentes: descubribles, ejecutables, observables y capaces de acumular memoria útil.

## PROOF

El conjunto de captures actuales converge en una sola tesis operativa: propiedades estructurales, CLI, logging, manifiestos, memoria por tipo y juicio del LLM funcionan mejor como una pila coordinada que como piezas aisladas.

## READER TRANSFORMATION

El lector deja de pensar en un skill como un prompt en Markdown y empieza a evaluarlo como infraestructura que debe soportar descubrimiento, invocación, depuración, almacenamiento, síntesis y curaduría.

## THREE HOOKS

1. Un skill que sólo le dice al agente qué hacer todavía no es un skill; es una nota con ambiciones.
2. El futuro de las herramientas para agentes tiene menos magia de prompt y más contrato aburrido.
3. Pensé que la memoria era el producto. Los captures muestran que la memoria es sólo una capa.

## THREE CLOSERS

1. Si el agente no puede descubrirlo, invocarlo, parsearlo y aprender de ello, el skill no está terminado.
2. La ventaja compuesta no es una ventana de contexto más grande; es un sistema local que conserva estructura y significado.
3. `$mem` debe convertirse en el lugar donde estos patrones dejan de ser referencias y pasan a ser valores por defecto operativos.
